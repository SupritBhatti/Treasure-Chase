# Tresure Chase

## Overview
Treasure Chase is a 2D platformer game developed as part of my A-Level Computer Science NEA. The game features combat, enemies, collectibles, scoring systems, and multiple gameplay mechanics designed using object-oriented programming principles. To run this game, use the "Treasure Chase.exe" file within the "Programs" folder.

## Features
- Player movement and jumping
- Combat system with shooting mechanics
- Enemies to deal with
- Coin collection system
- Score tracking and high score system
- Health and lives system
- Pause menu and game states
- Shop and power-up system
- Level progression

## Gameplay Mechanics
The player navigates platform-based levels, defeats enemies, collects coins and attempts to achieve the highest score possible.

### Controls
| Action | Key |
|--------|-----|
| Move Left | A |
| Move Right | D |
| Jump | Spacebar |
| Shoot | Left Mouse Click |
| Pause | P |
| Power-up | G |

## Technologies Used
